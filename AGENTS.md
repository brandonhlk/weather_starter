# Weather Starter

TypeScript weather app with a React/Vite frontend, Node/Express backend, SQLite persistence, and Singapore data.gov.sg weather integration.

## Repository-wide commands

Run these from the repository root:

```bash
npm run build       # Type-check/build frontend and compile backend
npm test            # Run backend Vitest tests
npm run dev         # Start the Portless development server
npm run start       # Run the compiled production server
```
